# Primer v0.1.0-alpha.2

Primer now understands more than Node repositories and makes discovered commands
available for reviewed execution.

- Python: pyproject/requirements detection, uv/Poetry/pip, version declarations,
  conventional FastAPI/Django/Flask and main.py launch patterns.
- Node/TypeScript: Next.js, Vite, Astro and Nuxt dependency identity; start fallback;
  Vite port evidence; existing package-manager scripts remain authoritative.
- Go/Rust: conventional binary entrypoints and build/test command discovery.
- General repositories: Procfile processes and simple Makefile targets.
- `primer commands`, `primer run NAME`, `primer why`; no implicit execution.
- Cleaner review composition, project-command browser, environment view and
  command-aware session dashboard. Every selected command requires review.
- Launch-evidence fingerprints cover the new manifest and entrypoint sources.

macOS/Linux ARM64/AMD64 archives and a checksummed installer are included. This
remains an alpha: one supervised command group; no Compose/database repairs,
package installation, detached state, health protocol or metrics.

See [README](https://github.com/desenyon/primer/blob/main/README.md),
[QA](https://github.com/desenyon/primer/blob/main/docs/QA-alpha.2.md) and
[implementation limits](https://github.com/desenyon/primer/blob/main/docs/STATUS.md).
