# Primer 0.1.0-alpha.1

The first runnable Node / Next.js milestone.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/desenyon/primer/v0.1.0-alpha.1/install.sh | sh
cd your-project
primer
```

Downloads are available for macOS and Linux, on ARM64 and AMD64. The installer
verifies SHA256 and the embedded version, then installs to `~/.local/bin`.
No Go toolchain or sudo is required. Add that directory to PATH if needed.

## Included

- Deterministic Node/Next detection with evidence and heuristic confidence.
- Package-manager and runtime checks, env-template diagnostics and port checks.
- Command review before execution, including predev/dev/postdev scripts.
- Supervised dev processes, bounded logs, filtering, restart and group shutdown.
- Ultramarine scan/review screens, dashboard, diagnostics and command palette.
- Plain and JSON inspection for scripts and CI.

## Scope

This is an alpha, not the full Primer MVP. Compose, Python, databases, automatic
repairs, per-service monorepo supervision and persistent sessions are upcoming.
The expected localhost URL does not establish application health.

See [the implementation checkpoint](https://github.com/desenyon/primer/blob/main/docs/STATUS.md)
for verification evidence and exact limits.
